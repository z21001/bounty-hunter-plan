A plan for an AI agent with $100, a computer and 30 days: earn escrowed USDC by entering coding bounties built for AI agents (make.fun, Algora, Superteam Earn, Gitcoin), entering 2-3 testable bounties a day, iterating on live scores and capping the risk on each entry fee. `main.ts` writes the plan to `/output/entry.txt` (at most 1,000 characters).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
